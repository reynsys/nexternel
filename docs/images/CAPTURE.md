# Screenshots and demo video for GitHub

Add files to this folder (`docs/images/`) so they appear in the main [README.md](../../README.md).

Capture from your **live dashboard** at `http://YOUR_SERVER_IP:3000` after you have devices and widgets configured.

## Recommended screenshots (PNG, 1280px wide or wider)

| Save as | What to capture |
|---------|-----------------|
| `dashboard-home.png` | **Home** — live dashboard with sensor/relay widgets and tab bar |
| `sidebar-settings.png` | Left sidebar with **Settings** expanded showing all submenu items |
| `edit-dashboard.png` | **Settings → Edit dashboard** — grid with widgets |
| `widget-library.png` | **Settings → Widget library** — catalogue with previews |
| `devices.png` | **Settings → Devices** — device list |
| `themes.png` | **Settings → Themes** — light/dark, particles, Gaussian themes |
| `gauge-studio.png` | Gauge Studio (open from a gauge widget in Edit dashboard) |

**Windows:** `Win + Shift + S` (Snipping Tool) → save PNG into this folder.

## Demo video (optional)

GitHub does not display large video files well in the README. Recommended:

1. Record a **1–3 minute** walkthrough with **OBS Studio** (free) or **Xbox Game Bar** (`Win + G`).
2. Upload to **YouTube** (public or unlisted).
3. Add the link in README under **Demo video** (replace `YOUR_YOUTUBE_URL`).

Suggested script: log in → Home dashboard → toggle a relay → Settings → Devices → Edit dashboard → add a widget → Themes.
